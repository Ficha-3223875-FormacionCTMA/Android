# 📱 Mi Formación CTMA

Aplicación móvil desarrollada en **Android Native** utilizando **Jetpack Compose** y **Material Design 3**. La interfaz está diseñada para ser completamente declarativa, adaptable a distintos tamaños de pantalla y accesible.

---

## 🚀 Características

* **Diseño Adaptable (Responsive):** Transición automática entre `LazyColumn` (dispositivos móviles) y `LazyVerticalGrid` (pantallas grandes/tablets).
* **Filtros Dinámicos:** Clasificación en tiempo real por estados de actividad (`Todas`, `Pendientes`, `En proceso`, `Completadas`).
* **Accesibilidad (a11y):** Semánticas descriptivas agregadas en las tarjetas para lectores de pantalla.
* **Componentes Material 3:** Uso de `Scaffold`, `TopAppBar`, `Card`, `FilterChip`, `LinearProgressIndicator` y `FloatingActionButton`.

---

## 🛠️ Tecnologías y Librerías

* **Lenguaje:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Iconos:** Material Icons Extended
* **IDE:** Android Studio

---

## 📦 Instalación y Configuración

1. Clona el repositorio desde GitHub.
2. Abre el proyecto en **Android Studio**.
3. Sincroniza las dependencias de Gradle (`Sync Project with Gradle Files`).
4. Ejecuta la aplicación en un emulador o dispositivo físico.
